# Nagar-Ek mobile app

The Expo Router mobile client for the Nagar-Ek sustainable-cities project. The repository-level [README](../README.md) covers the full app and backend setup.

## Run the app

1. Set `EXPO_PUBLIC_API_URL` in `.env` to the backend's reachable base URL, including `/api`.
2. Install dependencies and start Expo:

   ```bash
   npm install
   npm start
   ```

For emulator and device setup, see the [Expo documentation](https://docs.expo.dev/).
